## Poster and walkthrough

- [Social poster](contextlab-poster-1200x630.jpg): 1,200 x 630 pixel summary image based on the verified Story hero.

The walkthrough uses only saved public evidence. Its cursor points to the relevant control or decision. It does not call a model, replay a private session, or use a cloned voice.
